- **Status:** accepted · 2026-11-16
- **Context:** The project will be continued by different Claude sessions and by AJ himself, possibly months apart. Decisions made in chat are lost.

- **Consequences:** A few minutes per decision; anyone can reconstruct _why_ the code looks the way it does.
