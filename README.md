# Grammatik Gym

Master German grammar from **A1 to C2** in 15 minutes a day. Phone-first, works offline, no ads, no tracking.

- **162 grammar points** on one map, each with a short lesson in plain words, x-ray colour coding for cases, and practice.
- **Typed answers, instant diagnosis**: not just "wrong", but _which_ feature was wrong (case, ending, word order…) and the one rule to remember.
- **Spaced repetition (FSRS)** per grammar point with a fresh sentence every review, plus your **own mistakes as review cards**.
- **11 exercise types**: cloze, choice, transform, sentence builder with the Feldermodell, combine, error hunt, ending builder, paradigm, match, classify, dictation.
- **C1/C2 style trainers**: Nominalstil, Partizipialattribute, Konjunktiv I, Passiversatz, Modalpartikeln.
- **Verified content**: schema checks, LanguageTool, and a blind-solve review before any item is served.
